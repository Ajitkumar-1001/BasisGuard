# BasisGuard web app (`@basisguard/web`)

Next.js app for BasisGuard: the new-run form (`/runs/new`), run detail pages and the `/api/runs` route handlers. It binds to `127.0.0.1` only.

Setup, fixture-mode instructions, tests and limitations are in the [root README](../README.md). From the repo root, `pnpm dev` starts this app.
